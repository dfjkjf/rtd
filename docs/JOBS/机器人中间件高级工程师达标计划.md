# 机器人中间件高级工程师达标计划

> 目标岗位：机器人中间件高级工程师
> 岗位性质：**架构师路线**——中间件与系统平台整体架构设计 + 端到端性能优化 + 技术路线规划
> 与《岗位达标作战计划.md》的关系：作战计划练"性能专家"公共底座（工具链/内核原理/ROS2），
> 本计划聚焦本 JD 的**增量要求**：架构能力、零拷贝/共享内存、实时系统、Zenoh/Rust、AUTOSAR AP 深化
> 两份计划并行执行，公共部分不重复练

---

## 〇、为什么这是"梦想岗位"

- JD 重心是**中间件内核**（零拷贝/DDS/Zenoh/调度/工具体系），不要求 ROS2——避开短板、放大长板
- 加分项 2"熟悉通信中间件内部实现原理（CycloneDDS/FastDDS…）"= 您的核心竞争力原话
- 加分项 5"AUTOSAR AP（SM/EM/UCM）"= 现职已有集成经验
- 成长路径清晰：高级工程师 → 中间件架构师，符合长期职业方向
- 清醒提示：
  - 必备条件 1 要求计算机/自动化/电子相关专业，您的焊接专业有初筛风险 → 用战绩+内推对冲
  - 架构职责（设计文档/主导评审）是当前最需刻意练习的能力

## 二、分阶段计划（6 个月，与作战计划咬合）

### 阶段 0（第 1-2 个月，已在进行）：公共底座

- 复用《岗位达标作战计划》阶段一/二：ROS2 通关 + 性能工具链 + 监控工具 v0.1/v0.2
- 监控工具即本 JD 职责 4"调试方法论与工具体系"的作品集，从第一天起按架构级标准做

### 阶段 1（第 2-3 个月）：零拷贝与共享内存专项

**目标**：把 IPC 短板（必备 3）补成强项。

- [ ] 精读 FastDDS SHM Transport 源码（您有协议栈基础，读起来快）
- [ ] 研究 iceoryx2 架构：零拷贝原理、共享内存布局、发布订阅模型
- [ ] 动手：实现一个共享内存零拷贝 pub/sub demo（POSIX shm + 无锁环形队列）
- [ ] Benchmark：DDS-UDP vs DDS-SHM vs 自研零拷贝，输出延迟/吞吐/CPU 对比数据
- [ ] 产出：《机器人通信零拷贝方案对比与实测》文档（面试杀手锏）

**验收**：能讲清三种零拷贝路径的内存布局、同步机制与适用边界。

### 阶段 2（第 3-4 个月）：实时系统与确定性延迟

**目标**：拿下加分项 3、4（高优先级）。

- [ ] 搭建 PREEMPT_RT 内核环境，跑 cyclictest 记录延迟分布数据
- [ ] 写一个 1kHz 控制回路 demo：测量并优化 jitter（SCHED_FIFO + isolcpus + CPU 亲和）
- [ ] 与作战计划阶段三的内核调度学习合并：CFS vs RT 调度类对比实验
- [ ] ARM 特性：争取一块 ARM 板卡/Jetson 跑同样 benchmark；无条件则研读
      ARM 内存模型、cache 行为、ARM 下 perf 差异，整理笔记
- [ ] 整理国产 RTOS（翼辉/锐华）适配经验为"实时系统实战"案例

**验收**：手持 PREEMPT_RT vs 标准内核 cyclictest 对比数据 + 1kHz 回路 jitter 优化前后数据。

### 阶段 3（第 3-5 个月）：架构能力构建（本计划核心）

**目标**：补齐"架构师路线"最缺的能力（必备 6 + 职责 1/2）。

- [ ] 学方法论：C4 模型、ADR（架构决策记录）、接口规范写法
- [ ] 作品集 1：把监控工具升级为**正式架构设计文档**（背景/约束/方案对比/接口/风险）
- [ ] 作品集 2：产出一份《机器人中间件平台架构方案》——覆盖通信（DDS/Zenoh/零拷贝）、
      调度、工具体系三个子系统，模拟"职责 1"的完整交付
- [ ] 实战：在现职主导一次技术评审（哪怕只是监控工具方案评审），留会议纪要
- [ ] 前沿预研：Zenoh 原型验证 + 《DDS vs Zenoh 对比报告》（职责 5 的作品集）
- [ ] 通读公司平台/中间件架构，输出一份架构分析笔记（内部视角加分）

**验收**：两份设计文档 + 一次评审纪要 + 一份对比报告在手；能对着白板讲 30 分钟架构方案。

### 阶段 4（第 4-6 个月）：Rust 与工程化体系

**目标**：拿下加分项 1，落地职责 6。

- [ ] Rust 基础：《The Book》核心章节 + 练习题
- [ ] 小项目：用 Rust 写监控工具的一个组件或独立 benchmark 工具（放 GitHub）
- [ ] 工程化：为监控工具项目制定编码规范、CI 质量门禁（clang-format/tidy、ASan、覆盖率）
- [ ] 选做：io_uring 实验（加分项 6 的低成本切入点）；监控工具落盘模块做文件系统/
      I/O 策略选型记录（加分项 7）

**验收**：GitHub 上有 Rust 项目；监控工具仓库有规范文档与 CI 门禁配置。

### 阶段 5（第 6 个月）：成果固化与投递

- [ ] AUTOSAR AP 深化：研读 SM/EM/UCM 三模块职责，把现职集成经验整理成结构化案例
- [ ] 简历按本 JD 重写：架构能力（设计文档/评审）+ 中间件内核（零拷贝/协议栈）+
      实时系统（PREEMPT_RT/1kHz）+ 战绩数字，逐条对标
- [ ] 投递策略：**优先内推**（对冲专业初筛风险）；沟通话术主动说明专业背景与 6 年中间件战绩
- [ ] 模拟面试：找同行/社区做一次架构方案答辩演练

**验收**：新版简历对照 JD 自检——必备 7 条全有案例，加分项命中 4 条以上（2/3/4/5 必中）。
